# 简历信息结构选择器

## 原则

先确定内容架构，再选择渲染器。Renderer 只呈现内容，不决定事实、定位、项目取舍或措辞强度。

## 输入

- Role Pack 与目标 JD；
- 校招或社招、职级；
- 工作与项目数量；
- 内容密度和目标页数；
- 是否偏技术、业务、设计或运营；
- 是否有作品集、论文、开源或产品链接；
- 目标市场是否明确要求照片。

## 推荐结构

| 场景 | 内容优先级 | 默认 Renderer |
|---|---|---|
| AIPM / 技术产品 | 定位、项目证据、产品判断、验证、工作经历 | high-density-technical |
| 传统 B 端产品 | 定位、工作经历、项目经历、业务规模 | clean-professional |
| 研发 | 技术栈、项目、工程结果、工作经历 | high-density-technical |
| 设计 | 定位、作品集入口、项目、经历 | clean-professional，可定制作品入口 |
| 运营 | 业务指标、策略、执行、结果 | clean-professional |
| 校招经历较少 | 教育、项目、实践、技能 | clean-professional |
| 社招经历较多 | 定位、近期工作、核心项目、补充经历 | 根据技术密度选择，通常两页 |

## 页数决策

- 一页能保持完整证据和正常字号时使用一页；
- 压缩会删除独立项目、破坏可读性或让字号过小时，使用两页；
- 第一页放最强且最相关的可防守证据；
- 第二页放补充项目、早期经历、技能、教育或作品；
- 不用模板空白决定内容长度。

## 照片

默认不启用照片区域。只有用户明确要求，或目标市场/岗位存在明确需要时，才选择带照片的定制布局。本 Skill 内置 Renderer 不提供空照片框。
