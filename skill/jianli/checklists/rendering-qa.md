# 简历渲染与打印检查

HTML 生成后必须检查实际渲染和打印结果，而不只阅读源码。

## 页面

- [ ] 纸张为 A4，页边距稳定
- [ ] 页数符合内容架构决定
- [ ] 没有多余空白页
- [ ] 内容超过一页时自然扩展为两页，不以过小字号硬塞
- [ ] 标题不会孤立在页尾
- [ ] 经历或要点没有不合理拆页
- [ ] 两页之间没有巨大空白或内容重叠

## 可读性

- [ ] 中文字体正常且有系统回退字体
- [ ] 正文字号不低于 Renderer 声明的可接受下限
- [ ] 链接、长标题和长文本没有溢出
- [ ] 页面背景关闭时信息仍可读
- [ ] 视觉层级与内容优先级一致
- [ ] 默认没有空证件照框

## 编辑与打印

- [ ] 页面文字可选中、可编辑、可复制
- [ ] 编辑工具栏打印时隐藏
- [ ] 打印时不出现浏览器调试提示或编辑边框
- [ ] PDF 没有浏览器页眉页脚、URL 或日期
- [ ] PDF 中的中文文本仍可选择和复制
