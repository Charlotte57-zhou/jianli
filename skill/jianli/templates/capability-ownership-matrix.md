# Capability Ownership Matrix

Use one row per capability claim. Record the highest defensible level, not an aspirational level.

| Capability / claim | Evidence class | Evidence source | AI / other contribution | Explain | Modify / Debug | Reproduce | Real-world validation | Ownership level | Validation maturity | Boundary | Next proof |
|---|---|---|---|---|---|---|---|---:|---|---|---|
| | | | | Yes/Partial/No | Yes/Partial/No | Yes/Partial/No | Yes/No | L0–L5 | | | |

## Level decision

- L0 Exposure
- L1 AI-assisted Output
- L2 Explain
- L3 Modify / Debug
- L4 Reproduce / Validate
- L5 Real-world Validated

Do not infer L5 from production maturity alone. The candidate must also satisfy L4 ownership.
