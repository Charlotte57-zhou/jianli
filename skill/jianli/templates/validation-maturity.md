# Validation Maturity

Record the highest stage supported by evidence. Do not skip stages by implication.

| Stage | Minimum evidence | What it does not prove |
|---|---|---|
| Concept | problem and solution hypothesis | runnable behavior |
| Prototype | inspectable interaction or design artifact | reliable execution |
| Runnable Demo / POC | core path can run | systematic quality or real use |
| Offline Eval | declared cases, labels, metrics, denominator, and results | real-user value |
| Structured User Interview / Expert Review | documented participants, method, feedback, and decisions | repeated usage or production outcome |
| Pilot / Real User Usage | bounded real users, tasks, duration, and observed outcomes | general production reliability |
| Production | supported live workflow and operational evidence | measured business impact |
| Measured Business Outcome | defined metric, baseline, denominator, period, attribution, and result | universal causality outside the measured scope |
