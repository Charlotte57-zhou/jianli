# Role Packs

Role Packs add role-specific hiring knowledge on top of the generic Jianli Core.

## Available

- `ai-product-manager/` — AI Product Manager / Agent Product / LLM Application Product

## How a pack works

The Core decides:

- what is true;
- what is evidenced;
- what the candidate personally owns;
- how far the project was validated;
- which capability primitives are proven;
- which claims are defensible;
- how to quantify;
- how to tailor;
- how to preserve the master resume.

The Pack decides:

- what this role tends to value;
- how to translate evidence into role language;
- which portfolio artifacts matter;
- what role-specific mistakes to avoid.

## Pack precedence

```text
Candidate evidence
    >
Actual target JD
    >
Core integrity rules
    >
Role Pack defaults
```

A Role Pack never authorizes fabrication or upgrades Evidence Class, Ownership Level, Validation Maturity, or project explanation right.
