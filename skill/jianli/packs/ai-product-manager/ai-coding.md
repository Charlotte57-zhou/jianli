# AI Product Manager — AI Coding

## Do not write AI coding tools as a flat skill list

Weak:

> Codex, Claude Code, Cursor.

Better:

> Uses AI coding agents to translate requirements into pages, features, implementation tasks and acceptance criteria; collaborates with them to build runnable POCs, iterate functions, review changes and run automated tests.

## What this proves

For an AI PM, AI Coding may prove:

- higher prototype velocity;
- ability to communicate with engineering artifacts;
- better acceptance testing;
- ability to move from PRD to runnable product;
- technical curiosity and product-building ability.

It does **not** automatically prove:

- senior software engineering;
- production architecture expertise;
- independent code quality at engineering-hiring standards.

Keep the claim aligned with the target role.
