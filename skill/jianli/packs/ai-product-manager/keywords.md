# AI Product Manager — Keyword Guide

This is not a keyword stuffing list.

Only use a term when the candidate can explain what it meant in their project.

| Term | What it should mean | Evidence before using |
|---|---|---|
| LLM | Large language model is materially used in product behavior | actual model interaction / design |
| Agent | Model can plan/use tools/act across steps or investigate state | concrete agent loop / tool use |
| Workflow | Multi-step product/business flow | actual flow design |
| Tool Calling / Function Calling | Model invokes external capabilities | tool/API integration |
| RAG | Retrieval augments model context | retrieval pipeline actually exists |
| MCP | Model Context Protocol used in implementation/integration | actual MCP usage |
| Human-in-the-loop | Human approval/review is designed into decision/action flow | explicit control point |
| Eval | Systematic evaluation beyond anecdotal demos | dataset/rubric/metrics/gates |
| POC / Demo | Runnable proof of concept | actual artifact |
| AI Coding | AI coding agent materially supports implementation | repeatable workflow |
| Prompt | Prompt design is materially part of behavior | actual prompting work |
| 0→1 | Candidate helped define and deliver a new product/capability | real ownership boundary |

## Important

If the JD says RAG and the candidate has no RAG evidence, do not add RAG.

If the candidate used a deterministic rules layer plus Agent investigation, say that clearly. Showing where AI is **not** used is often a stronger product signal.
